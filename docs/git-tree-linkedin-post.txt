I got tired of switching between VS Code and a separate Git app, so I built one into the editor.

It's called Git Tree, a free, open-source VS Code extension.

What it does:

🌳 A real commit graph, your branches, the changed files and the diff, side by side in one panel
🖱️ Double-click a commit to check out its branch, or right-click it to see its details and act on it: merge, rebase, cherry-pick, revert, reset, tag, archive and more
📂 Worktrees: have two branches checked out at once in separate folders, so you can review a pull request without stashing what you're working on
✅ Stage single lines or hunks with checkboxes
📦 Stashes, merge-conflict help, several repositories as tabs, keyboard shortcuts for everything, and themes
✨ Draft a commit message with the AI model you already use in VS Code, then commit and push in one step
🔀 Pull requests for GitHub, Azure DevOps, GitLab and Bitbucket, inside the editor

The part I care about most: every button shows the exact git command before it runs, and you can edit it. Everything that ran goes into a log. It's a GUI that teaches you git instead of hiding it.

It runs your local git and sends no telemetry. MIT licensed.

I'd love feedback from anyone who lives in VS Code and Git all day. What would make you switch from your current Git client?
